# Rock Paper Scissors

A Rock Paper Scissors game made with Python.

## About

This project is a Rock Paper Scissors game, and it's my first project in Python

It was made in order to learn Python and practice with it.

## Features

The game lets you play against the computer in a single round of the game, in which both the player and the computer choose either Rock, Paper or Scissors, and the game ends by displaying who won the game, or if it's a draw.

## Technologies

This was a small project made solely with Python, and one built-in module called "random".

## How To Run
To run the program, you have to do the following steps:
1. Clone this repository to your local machine.
2. Open the project's directory.
3. Run the following command:
python main.py
